## 2. 逐实验明细

### E0 轻量基线（2026-11-19）

- **目的**：给出「纯数值、无 LLM」的性能锚点，用于 C4 与后续对照。
- **方法**：79 维 `scaled_features` → MLP（本机 CPU，`scripts/eval_light_baseline.py`）。
- **数字**：闭集 acc 0.9855、macro-F1 0.9858；OOD（max-softmax）AUROC 0.8323、`tpr@fpr=1%` 0.0450；训练 594 s；推理 0.098 ms/样本。
- **产物**：`results/2026-11-19/e0_baseline/metrics.json` `[本地]`

### E8.1 文本↔特征可预测性

- **目的**：检验 H1「文本是特征的重编码」。
- **数字**：79→768 的 R² = **0.498**（线性）；768→79 的 R² = **0.691**。
- **读法**：文本向量有一半方差可由 79 维数值特征线性解释；反向更高，说明文本是特征的平滑投影。
- **产物**：`results/2026-11-19/e8_audit/metrics.json` `[本地]`

### E8.2 条件互信息

- **目的**：检验「给定特征后，文本是否还带标签信息」。
- **数字**：logreg 估计 `I(text;y|features)` = +0.121 nats（判为估计器伪影）；HGB 复核 = **−0.020** nats，CI95 [−0.041, −0.004]，相对 H(y)=2.30 可视为 0。
- **判定**：**机制项通过**（无正信息增量）。
- **产物**：`results/2026-11-19/e8_audit_hgb/metrics.json` `[本地]`

### E8.3 扰动审计（含阳性对照）

- **目的**：检验模型是否依赖文本内容的变化。
- **主协议**：同类 donor 替换 20 个字段值（文本重生成、句式不变），特征侧同字段替换作对照。
  - 文本侧翻转 **2.42%** CI[1.69, 3.14]；特征侧 3.38% CI[2.54, 4.23]；两侧均不变 94.4%；差值 CI 跨零。
  - 原 acc 0.9939（与 A0* 一致，sanity 通过）。
- **阳性对照**：跨类 donor，
  - 文本侧 **66.2%** CI[63.9, 68.3]；特征侧 10.1% CI[8.6, 11.5]。
- **判定**：门槛（<20%）通过；但阳性对照证明**文本分支高度敏感**，故「模型并未真正读文本」的解读不成立。E8.3 只支持「同类内文本扰动不改变判定」。
- **产物**：`results/2026-11-20/e83_perturbation/metrics.json`、`e83_perturbation_cross/metrics.json` `[本地]`

### E8.4 去文本消融

- **旧产物**（2026-09/10 检查点）：11 对同 seed 配对 +20.4pp，但 no_text 闭集仅 0.54–0.71，跨批次混淆 → **不作证据**。
- **重训版（C-30，2026-11-20）**：`scripts/train.py --variant "A0*_no_text"`，seeds 42–46，epochs 10、batch 4、grad-accum 2、lr 5e-4；闭集评估用 `scripts/eval_closed_set.py`。

| seed | model_id | 已知类 acc |
|---|---|---|
| 42 | model_5023 | 0.9825 |
| 43 | model_5024 | 0.9807 |
| 44 | model_5025 | 0.9740 |
| 45 | model_5026 | 0.9843 |
| 46 | model_5027 | 0.9819 |
| 均值 | — | **0.9807 ± 0.0039** |
| A0* 基准 | model_2013 | **0.9940** |

- **Δ = −1.33pp**，5-seed bootstrap CI95 **[−1.67, −1.08]** → 未达 C-30 判据（CI 下界 > −1pp）→ **不能声称「文本可省」**。
- **解释边界**：该消融同时移除 Qwen1.5B+LoRA 容量，Δ 与容量混叠，**不能反推文本携带信息**；no_text（0.9807）低于 E0 纯数值 MLP（0.9855），支持容量解释。
- **产物**：`results/2026-11-20/e84_retrain/{metrics.json, model_2013.json, model_5023–5027.json}` `[本地]`；检查点 `saved_models/model_5023–5027` `[仅远端，各 18MB]`

### E3 / E4 零样本与少样本（BERT 空间）

- **方法**：每类 3 条描述（类名 + KB detection + 行为模板）→ BERT 编码 → 原型；P_rand / P_shot / P_llm / P_mix(α)；距离与 α 在 val 选，test 只评一次；5 seeds。
- **E3 零样本**：acc **0.1281**、macro-F1 0.050（距离 cosine）→ 未达 0.50。
- **E4 少样本**：P_shot k=1/5/10/20 = 0.4481 / 0.5078 / 0.5190 / 0.5175；P_llm 0.1281；P_rand 0.09–0.12；val 上各 k 均选 α\*=0 → Δ=0 CI[0,0]。
- **产物**：`results/2026-11-20/e3_e4_bert/{metrics.json, curve.csv}` `[本地]`；原型 `emb/bert_protos.npz` `[仅远端]`

### E5 零样本/少样本（Qwen1.5B 空间）

- **数字**：零样本 **0.1462**；P_shot k=1/5/10/20 = 0.1782 / 0.1861 / 0.2268 / 0.2329；α\* 仅 k=1 取 0.75（Δ +0.44pp CI[−0.64,+1.49]）、k≥10 取 0。
- **判定**：未达标；负结论在 Qwen 空间复现且更弱。
- **产物**：`results/2026-11-20/e5_qwen/metrics.json` `[本地]`；`emb/qwen_texts.npz`、`emb/qwen_protos.npy` `[仅远端]`

### E6 开集三臂（随机 / 语义热启动 / 混合）

- **BERT**：AUROC 0.7407 → 0.7584；`tpr@fpr=1%` 0.0000 → **0.0045** CI[0.00, 1.35] → 未达 +2pp。
- **Qwen1.5B**：AUROC 0.6139 → **0.4643**（热启动更差），tpr 均 0。
- **告警**：P_rand 的 tpr（3.6%）高于热启动，说明**不同原型集合的距离尺度不可直接比较**，原型距离型 OOD 分数需校准。
- **产物**：`results/2026-11-20/e6_bert/metrics.json`、`e6_qwen/metrics.json` `[本地]`

### E7 原型构造消融

- **范围**：描述来源（类名 / KB 检测线索 / 行为模板）× 原型条数（1/2/3）× 距离（cosine/euclidean）。
- **数字**：BERT 0.0961–0.1281；Qwen 0.1027–0.1462，全部接近随机水平。
- **判定**：描述不是瓶颈（描述性实验，无门槛）。
- **产物**：`results/2026-11-20/e7_ablation/metrics.json` `[本地]`

### E9 容量阶梯（Qwen2.5-7B）

- **数字**：零样本 **0.1130**；P_shot k=20 0.2202；开集 AUROC **0.4767**、tpr 0.0000；Δtpr（vs BERT）= 0。
- **判定**：容量无效；AUROC 随规模单调下降（0.741 → 0.614 → 0.477）。
- **产物**：`results/2026-11-20/e9_qwen7b/metrics.json` `[本地]`；模型权重 `models/qwen2.5-7b` `[仅远端，约 15GB]`

### C4 成本-精度（第 7 章）

- **协议**：batch=1、warmup 20、max_length 256、每次迭代 `torch.cuda.synchronize()`、RTX 4080 SUPER 32GB、同一实例。
- **数字**：

| MLP 79 维（CPU 单线程） | 0.035 ms | 0.9855 | 1× |
| MLP 79 维（GPU） | 0.103 ms | 0.9855 | 3× |
| BERT 编码 | 7.07 ms | 0.5175（20-shot） | 205× |
| Qwen1.5B 原型 | 36.36 ms | 0.2329（20-shot） | 1040× |

- **产物**：`results/2026-11-20/c4_latency/{metrics.json, fig5_pareto.png, c4_tables.md, make_fig5.py}` `[本地]`；脚本 `scripts/bench_latency.py` `[仅远端]`

## 7. 已知限制与后续

1. **E8.4 与容量混叠**：`A0*_no_text` 同时移除文本与 LLM 容量，Δ 不可单独归因；正文必须并置 E8.1/E8.2 与该项，不得只取有利一侧。
2. **E8.3 功效有限**：同类扰动下 94.4% 样本不变，只能支持「同类内不敏感」。
3. **E6 距离尺度不可比**：随机原型的 tpr 反而更高，原型距离型 OOD 需校准后才能横比。
4. **单数据集、单文本模板**：所有结论限于 CIC-IDS2017 与 `generate_text_description` 的模板，不得外推到其他数据集或自然语言日志。
5. **第 6 章其余四张表（6-1～6-4）与正文尚未撰写**：数字均已落在 `metrics.json`，只差成文。
6. **E8.4 可视化已完成**（图 6），但尚差正文段落与表 5-5 的正式排版。
