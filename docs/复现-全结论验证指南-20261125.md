## 0. 先读这一节：什么叫"验证成功"

本项目的结论分三类，验证方式完全不同：

1. **数值型结论**（C-01–C-16、C-19–C-35）：重算指标，与 `claims.md` 冻结值比对。
2. **机制型结论**（C-28 的 E8 链）：重跑确定性审计（文本=f(字段)、R²、条件互信息、扰动翻转率）。
3. **人工评测结论**（C-17、C-26、C-27）：**无法自动复现**，只能复核盲标表与统计过程，或重新组织人工标注。

因此本指南用五级复现等级：

| 级别 | 含义 | 典型耗时 | 需要什么 |
|---|---|---|---|
| **L0 只读复核** | 只读已入库的 JSON/CSV，重算统计量 | 秒级 | 仅 git 仓库 |
| **L1 精确复现** | 同数据、同代码、同 seed，指标逐位一致（容差 1e-9） | 分钟级 | git + Release 数据包（+ `emb/`） |
| **L2 复算/生成** | 用已发布报告/头/已训模型重算，或重新生成解释 | 分钟–小时 | Release 资产 + GPU + 基座模型 |
| **L3 从零重训** | 重新训练 backbone / OOD 头 / 消融 | 小时级 | GPU + 原始 CSV + 基座模型 |
| **L4 人工盲评** | 重新做盲标、κ、配对检验 | 人日级 | 标注人 + 协议 |
| **N/A** | 尚无实验，无法复现 | — | 需先做新实验 |

**判定纪律**（与 `claims.md` §0 一致）：

- `已证实`：必须同时给出效应量与区间；数值必须能重算。
- `未支持`：只能写"不支持 / 不可区分"，**禁止**反向断言。
- `待检验`：不得进入摘要。
- 任何级别出现**结论方向翻转**（例如 CI 由跨零变为不跨零且越过门槛）→ 先查数据哈希与环境版本，再讨论写法。
