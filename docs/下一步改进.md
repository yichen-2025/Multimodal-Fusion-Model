本文档说明两个改进步骤的具体实施方法：引入验证集、引入早停机制。

```
步骤1：引入验证集  →  步骤2：引入早停机制
    （基础）              （依赖验证集）
```

## 步骤1：引入验证集

### 修改文件

- `split_modality.py` — 数据划分逻辑
- `src/data/data_loader.py` — 数据加载（如需新增val加载函数）
- `train.py` — 训练时加载验证集

### 具体改动

#### 1.1 split_modality.py — 增加 val_size 参数

在函数签名中添加 `val_size` 参数：

```python
def split_modality(dataset_id=0, split_id=None, test_size=0.2, val_size=0.1, random_state=42):
```

#### 1.2 split_modality.py — 三划分逻辑

将原来的一次 `train_test_split`（训练/测试）改为两次划分：

```python
# 第一次划分：分出测试集
X_temp, X_test, bert_temp, bert_test, y_temp, y_test, df_temp, df_test = train_test_split(
    X_scaled, bert_embeddings, labels, df,
    test_size=test_size, random_state=random_state, stratify=labels
)

# 第二次划分：从训练集中分出验证集
val_ratio = val_size / (1 - test_size)  # 相对于temp集的比例
X_train, X_val, bert_train, bert_val, y_train, y_val, df_train, df_val = train_test_split(
    X_temp, bert_temp, y_temp, df_temp,
    test_size=val_ratio, random_state=random_state, stratify=y_temp
)
```

#### 1.3 split_modality.py — 保存验证集

新增验证集保存：

```python
np.savez(os.path.join(output_dir, "val.npz"),
         scaled_features=X_val,
         text_embeddings=bert_val,
         labels=y_val)
df_val.to_csv(os.path.join(output_dir, "val_data.csv"), index=False)
```

#### 1.4 train.py — 加载验证集

在训练数据加载处增加验证集加载：

```python
val_dataset = load_split_data(data_dir="split_data", data_type="val",
                              dataset_id=dataset_id, split_id=split_id)
```

### 验证方法

运行 `split_modality` 后检查输出目录下有 `train.npz`、`val.npz`、`test.npz` 三个文件，样本数比例约为 7:1:2。

## 步骤2：引入早停机制

### 修改文件

- `train.py` — 训练参数、回调、评估函数

### 具体改动

#### 2.1 新增 compute_metrics 函数

在 `train_model` 函数内或文件顶部添加：

```python
import numpy as np
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    return {
        'accuracy': accuracy_score(labels, predictions),
        'precision': precision_score(labels, predictions, zero_division=0),
        'recall': recall_score(labels, predictions, zero_division=0),
        'f1': f1_score(labels, predictions, zero_division=0),
    }
```

#### 2.2 修改 TrainingArguments

调整评估和保存策略：

```python
training_args = TrainingArguments(
    output_dir=output_dir,
    per_device_train_batch_size=per_device_train_batch_size,
    gradient_accumulation_steps=gradient_accumulation_steps,
    learning_rate=learning_rate,
    num_train_epochs=num_train_epochs,
    bf16=True,
    logging_steps=10,
    report_to="none",
    remove_unused_columns=False,
    # ---- 新增 ----
    evaluation_strategy="epoch",       # 每个epoch评估
    save_strategy="epoch",             # 每个epoch保存
    load_best_model_at_end=True,       # 结束时加载最佳模型
    metric_for_best_model="eval_f1",   # 用F1选最佳
    greater_is_better=True,
    save_total_limit=3,                # 只保留最近3个checkpoint
)
```

#### 2.3 添加 EarlyStoppingCallback

在 Trainer 创建处添加：

```python
from transformers import EarlyStoppingCallback

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=val_dataset,          # 验证集（步骤1提供）
    data_collator=custom_collate,
    compute_metrics=compute_metrics,   # 评估函数
    callbacks=[
        LossLoggerCallback(loss_log_dir),
        EarlyStoppingCallback(early_stopping_patience=3)  # 连续3轮不提升则停止
    ]
)
```

### 验证方法

训练时观察输出：每个epoch结束会打印 `eval_f1` 等指标；若连续3轮F1不提升，训练自动停止并加载最佳模型。

---

## 改动影响汇总

| 步骤 | 涉及文件 | 新增依赖 | 对现有流程的影响 |
|------|---------|---------|----------------|
| 验证集 | `split_modality.py`, `train.py` | 无 | split输出多了val.npz；训练时多做验证评估 |
| 早停 | `train.py` | 无（transformers内置） | 训练可能提前终止；自动加载最佳模型 |

---

## 测试建议

每完成一个步骤，运行一次完整训练，对比基线结果：

- **步骤1完成后**：确认验证集F1与测试集F1趋势一致
- **步骤2完成后**：确认早停能正确触发，最佳模型优于最终epoch模型
