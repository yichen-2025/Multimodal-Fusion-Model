# 第 4 章 LLM 作为文本编码器的受控评测

> 初稿（2026-11-20）。数字来自 `results/2026-11-03/{ood_multiseed_fair_encoder_n5.json,bootstrap_ood_ci_fair_encoder_n5.json,ood_multiseed_with_a3.json,bootstrap_ood_ci_with_a3.json}` 与 `docs/stage_conclusion_20261103.md`；其中 fair-encoder 两份产物仅云端正本，本地快照在 `.cloud_snapshot/results/2026-11-03/`。结论状态以 `claims.md` C-25 / C-05 / C-06 / C-07 / C-19 / C-22 / C-23 / C-24 为准。

第 3 章定义了三条主干。本章回答第一个实证问题：把文本编码器从 BERT 换成 Qwen2.5-1.5B（挂 LoRA），开集检测是否变好？结论先行：**在 5 seed、对齐 batch/epoch/pooling/adapter 的受控对照下，LLM 主干相对最佳 no-LLM 变体在 `tpr@fpr=1%` 上没有可检测增益**；已有的差异是指标间的 trade-off，不是单向占优。

## 4.1 对照设计

比较的难点不在跑模型，而在把"主干差异"从"训练配置差异"里剥离出来。本章做三件事。

**第一，对齐训练配置。** 所有变体使用同一 train/val/test、同一数值编码器、同一 epoch 与 batch、同一 pooling 位置、同一 adapter 插入点；差异只落在文本侧实现（BERT 对 Qwen+LoRA）或融合方式上。参与主对照的是 `A0*`（Qwen1.5B + LoRA）与 `A3`（冻结 BERT），各 5 个 backbone seed（42/123/456/789/1011），配对比较。

**第二，只把开集指标当判据。** 闭集上这组变体已经饱和：4 个 A0\* 变体在 3 个 seed 下的准确率为 0.9915–0.9944，差距不可区分（C-01）；A3 系比 A0\* 低 1–2pp，但这是闭集容量差异、不是 OOD 能力（C-02）。因此本章的判定只依赖 `auroc_genuine`、`tpr@fpr=1%` 与 `unknown_recall_simulated`（recsim），且三者成对报告。

**第三，门槛事先固定。** G1 判据为：`tpr@fpr=1%` 上 LLM 侧相对最佳 no-LLM 变体 ≥2pp，且配对 bootstrap（B=4 000，同时重采样样本与 seed）95% CI 不跨零。未过门槛时只能判"未支持"，不得反向断言"LLM 无用"。

判据选 `tpr@fpr=1%` 而不是 AUROC，有明确的方法学理由（C-07）：AUROC 衡量全阈值区间的排序，而安全运营只在极低误报区间取操作点；同一批报告里 AUROC 占优、低 FPR 落后是常见组合。把 AUROC 单独当结论，会系统性高估部署价值。

## 4.2 结果：无检测增益

**主对照（C-25）。** 5 seed 下 `A0*` 的 `tpr@fpr=1%` 为 8.78% ± 0.79%，`A3` 为 6.91% ± 9.20%，配对差 +1.87pp，95% CI [−8.85, +12.59]，p=0.549（表 4-1）。差值方向为正，但区间跨零且宽达 21pp，未过"≥2pp 且 CI 不重叠"的门槛，判**未支持**。

**表 4-1 G1 主对照（`tpr@fpr=1%`，n=5）**

| 臂 | 文本编码器 | 均值 ± sd | 配对差（A0\* − A3） | 95% CI | p |
|---|---|---|---|---|---|
| A0\* | Qwen2.5-1.5B + LoRA | 8.78% ± 0.79% | +1.87pp | [−8.85, +12.59] | 0.549 |
| A3 | BERT-base（冻结） | 6.91% ± 9.20% | | | |

> 差值为正不等于 LLM 更好：`A3` 的 seed 间方差几乎全部来自 seed 789 一个点（23.12%），它把均值抬高、把 CI 撑宽。逐 seed 表见 `docs/研究思路与论证链.md` §6.1；按写作红线，该表只作方差诊断，不作证据，也不允许事后剔除该 seed。

**单模态 LLM 文本与多模态 BERT 的对照（C-05）。** `A3`（数值 + BERT）与 `A0*_no_num`（仅 LLM 文本、无数值）在三个指标上不可区分——`auroc_genuine` −0.28pp [−1.41, +0.71]、`tpr@fpr=1%` −2.16pp [−4.03, 0.00]、recsim +0.82pp [−1.72, +3.25]，全部跨零。单靠 LLM 文本即可达到与"数值 + BERT"同等的开集水平，说明判别信息主要来自两条支路共有的部分，而不是 LLM 文本新增的部分。需要注意，这条对照两边模态不同，不能读成"两个文本编码器等价"；文本编码器的直接对照是上一段的 C-25。

**trade-off 而非单向占优（C-06）。** 在另一组多种子对照（`ood_multiseed_with_a3`）中，`A3` 相对 `A0*` 呈相反方向：`auroc_genuine` +2.08pp [1.16, 2.99]，但 `tpr@fpr=1%` −5.71pp [−7.50, −3.15]、recsim −4.29pp [−8.17, −0.77]，三个区间均不跨零。读法是：BERT 主干的排序更平滑（AUROC 更高），LLM 主干在低误报区与模拟未知上更差。两组数字来自不同运行，不能拼接成"某一方全面更优"。

**变体消融。** 三个单点改动同样没有改变判定（表 4-2）。`A0*_last`（mean→last pooling）三项均跨零；`A0_frozen`（冻结 LLM 主体）AUROC 更高但低 FPR 与 recsim 更差，是明确的 trade-off；`A3_adapter` 三项均跨零，闭集 0.9403 对 0.9253 的差异也不构成开集增益。

**表 4-2 变体差值（单位 pp；方向见首列，括号内为 95% CI，跨零者不标 CI）**

| 对照 | ΔAUROC | Δ`tpr@fpr=1%` | Δrecsim | 判定 |
|---|---|---|---|---|
| A3 − A0\*_no_num（C-05） | −0.28 [−1.41, 0.71] | −2.16 [−4.03, 0.00] | +0.82 [−1.72, 3.25] | 未支持 |
| A3 − A0\*（C-06，另一组） | +2.08 [1.16, 2.99] | −5.71 [−7.50, −3.15] | −4.29 [−8.17, −0.77] | trade-off |
| A0\*_last − A0\*（C-22，n=3） | +0.04 | −1.47 | +1.23 | 未支持（均跨零） |
| A0_frozen − A0\*（C-23，n=3） | +3.47 [2.96, 3.99] | −2.68 [−5.29, −0.08] | −7.57 [−10.74, −4.39] | trade-off |
| A3_adapter − A3（C-24，n=5） | +0.60 | −3.74 | −1.72 | 未支持（均跨零） |

**从"不确定"到"未支持"。** 按 `best_llm − best_no_llm` 口径，`A0*` 相对 `A3_adapter` 呈 `tpr@fpr=1%` +5.61pp [3.02, +8.20]、`auroc_genuine` −3.52pp [−6.71, −0.32]（C-19），仍是方向相反的 trade-off；当时 5 变体 × 5 seed 的 G1 判定只能是"不确定"。补齐严格对齐的主对照后，C-25 才给出终局判定"未支持"。这一过程本身值得记录：不确定性来自"最佳 no-LLM 臂取谁"与方差，而不是方向稳定的小增益。

综合来看，本章的证据结构与"LLM 略好但没显著"不同：主对照的差值方向为正、区间跨零；单模态对照的差值有正有负、且全部跨零；两组 trade-off 说明不同指标会选出不同赢家。因此正确表述是"**无可检测增益**"，而不是"LLM 无效"或"BERT 更好"。

## 4.3 判定边界

本章的结论受两层限制，必须在正文写清，不能留给读者自行推断。

**功效不足。** 222 条真实未知使 `tpr@fpr=1%` 的二项 CI 约 ±2.7pp；A3 的 seed 间 sd 达 9.20pp，噪声远大于待检效应 2pp。21pp 宽的 CI 只能排除"LLM 带来 >12.6pp 增益"这种大效应，无法排除 2–5pp 的小增益。要检出 2pp 约需上百个 seed，这在本研究的算力预算内不可行。因此本章不声称"两者等价"，只声称"在本设计的功效内未检测到增益"。

**比较范围。** 主对照只覆盖 BERT 与 Qwen2.5-1.5B 两个文本编码器；E9 的容量阶梯（110M→1.5B→7B）在第 6 章用于原型路线，不改变本章的判定。未测 API 模型、未测联合微调（`A3_ft` 因 BERT 离线预算、`@torch.no_grad()` 与权重不落盘而无法构成真变体）、未测多未知家族（C-18 仍为待检验）。

这两条限制指向同一个后续问题：如果换编码器、换容量、换融合方式都动不了开集指标，那么瓶颈可能不在模型侧。第 5 章因此转向数据侧，检查文本模态到底携带了多少特征之外的标签信息。
