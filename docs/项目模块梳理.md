## 一、项目一句话概览

一个**多模态融合**的网络流量恶意检测模型：每条流量取「数值统计特征」（当前数据集 **79 维**）+「中文自然语言描述」（**20 个语义字段**，模板化文本），分别编码后在 **LLM 外部**融合，再送入分类头。

- **LLM（Qwen2.5-1.5B）不做分类器**，只当「文本语义编码器」（mean pooling → 1536 维），可选 LoRA（q/v, r=8）做领域适配；
- **BERT（bert-base-chinese）** 仅在 A3 基线中充当文本编码器（768 维）；
- 项目分三个阶段递进：**P0 闭集分类** → **P1 开集未知攻击（OOD）+ 少样本** → **P2 语义解释 + CTI-RAG**（当前分支重心）。

5. `src.*` → `utils.{flow_features,caliber}`（**核心源码层反向依赖支撑层，是"口径唯一"的直接结果**）
6. `src.explain.*` → `src.model_architectures.multi_modal_model`（解释层复用主干做实时预测）

### 4.3 三条主线

- **P0 闭集**：`clean → subset → split → train → test/ablation`。验证模态组合与 LLM 用法的有效性。
- **P1 开集 + 少样本**：建立在 P0 已训主干之上，`openset + fewshot → ood_train → ood_eval / experiment → report`。核心假设：A0\*（LLM 融合特征）比 A3 更具 OOD 可分性。
- **P2 解释 + CTI-RAG**（当前分支重心）：`backbone 预测 → 分层抽样 → BM25 检索证据 → LLM 生成解释 + MITRE 映射 → 离线评估`。

### 4.4 解耦点与共享资产

- **OOD 头共享设计**：A3 / A0_frozen / A0\* 共用同一原型距离头结构，只在各自融合特征上训练，从而比较"特征质量"而非头结构差异。
- **解耦点**：`fusion_projection` 只管融合；`multi_modal_model` 管组合与推理；`ood_head` 从 `extract_fusion_features` 取特征，与分类头解耦。
- **解释层与判类路径解耦**：`generate_unknown_explanations` 只读路由报告、不写回，保证路由指标逐位不变。

### 4.5 口径体系（三级 fail-fast）

这是本项目区别于普通实验代码的核心约束，改动数据/模型/评估时必须走这条链：

```
flow_features（特征与文本 schema）  ──┐
open_set_eval（开集指标唯一实现）    ──┼──► caliber（标签空间/报告 schema 断言）
label_config（12/15 类映射）        ──┘         │
                                                ▼
                             verify_caliber.py（跑在 CI 式验收点）
                                                ▼
                             artifacts/ledger.csv（产物状态唯一判据）
```

**规则**：任何脚本不得重复定义数值列/文本模板/开集指标；一旦重复即视为 bug（历史上因此产生过报告口径不一致）。
